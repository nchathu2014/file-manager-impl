# core modules used

### readline
- The **readline module** in Node.js provides an interface for reading data from a Readable stream (like process.stdin) one line at a time. It's particularly useful for creating command-line interfaces and processing text input line by line.

- The **os module** in Node.js provides operating system-related utility methods and properties. It allows your Node applications to interact with the underlying operating system, retrieving information about the environment your code is running in.
